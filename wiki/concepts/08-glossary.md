# 名詞表

| 名詞 | 白話解釋 | 來源 |
|---|---|---|
| ATS（Applicant Tracking System） | 幫公司收履歷、整理、搜尋、追蹤招募進度的軟體 | src-06 |
| AEDT（自動化僱用決策工具） | 紐約法律用語：用機器學習、統計建模、資料分析或 AI，實質協助或取代裁量式僱用決策的工具 | src-03 |
| 偏差稽核（bias audit） | 由獨立稽核員檢查工具對不同性別、種族族裔群體的選取率或評分率是否有差異 | src-03 |
| 影響比率與 0.8 基準 | 各群體選取率與最高群體的比值；常以 0.8（四分之五法則）作為參考基準 | src-05 |
| Knockout 問題 | 依應徵者答案直接取消資格的篩選問題，如工作許可、必要證照 | src-07 |
| Sourcing（搜尋人才） | 招募者主動在履歷資料庫或網站搜尋符合條件的人，不是篩選新投遞的申請 | src-07 |
| 語意比對 | 不只比對相同字詞，而是理解意思相近的用語；McMaster 描述 AI 能詮釋語言與脈絡，Huntr 提到 Workable 使用語意分析 | src-06、src-07 |
| 高風險 AI | 歐盟以 Annex III 列出的類別（含招募選拔）；台灣基本法第 5 條規定由主管機關認定，標準尚未訂 | src-01、src-15 |
| 人為推翻 | 招募人員可推翻系統排名；但歐盟官方頁面指出，只要排名是主要輸入，仍屬高風險 | src-01 |
| 特別法與普通法 | 就業服務法第 5 條為特別規定，優先於個資法適用 | src-19 |
| 特定目的外利用 | 個資只能在蒐集時的目的內使用；業者主張把履歷給 LLM 是否超出目的是爭議 | src-20 |
| 隱私資料（就服法） | 雇主招募不得要求提供非屬就業所需之隱私資料 | src-14 |
